MYCELIUM BASE: WINDOWS BUILD

Fastest (no Python needed):
1. Create a GitHub repo and upload this folder (keep the .github folder).
2. Open the Actions tab, pick "Build Windows exe", click Run workflow.
3. When it finishes, download the MyceliumBase-windows artifact. It contains MyceliumBase.exe.

Local build (Windows):
1. Install Python 3 from python.org (tick "Add python.exe to PATH").
2. Double-click build_exe.bat. The exe appears in dist\.

Needs Microsoft Edge WebView2 (already on most Windows 10/11 PCs).
